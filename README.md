# Joy of Nav 프로토타입

표준 게임패드로 브라우저 페이지를 탐색하는 Chrome Manifest V3 확장입니다. 포커스된 탭 하나가 게임패드 입력을 처리합니다. 평상시 X로 스페이스 바를 입력하고, L스틱 spotlight 중에는 X로 탐색 후보를 순회합니다. L3 고정과 일반 브라우징용 가상 커서 및 키 입력 매핑도 제공합니다.

L스틱 spotlight 방향은 입력의 잔떨림을 줄이도록 부드럽게 보정됩니다.

## 빌드 및 설치

Node.js 20.11 이상과 Chrome이 필요합니다.

```powershell
npm install
npm run build
npm run package
```

Chrome에서 `chrome://extensions`를 열고 개발자 모드를 켠 뒤 `dist/` 폴더를 **압축해제된 확장 프로그램을 로드**로 불러오세요. 모든 지원 사이트에서 실행하려면 확장 세부 정보의 사이트 접근 범위를 모든 사이트로 허용합니다. 최신 패키지는 `release/joy-of-nav-prototype-latest.zip`입니다. 빌드할 때마다 버전별 ZIP과 최신 ZIP을 함께 갱신합니다.

Chrome은 `<all_urls>`가 지정한 지원 URL에 스크립트를 자동 주입합니다. `chrome://` 같은 브라우저 내부 페이지에서는 실행할 수 없고 `file://` 페이지는 확장 세부 정보에서 파일 URL 접근을 허용해야 합니다. 확장을 새로 설치하거나 업데이트한 직후 열려 있던 탭은 한 번 새로고침해야 합니다. 툴바 팝업에서 현재 문서 입력을 일시 중지·재개할 수 있습니다.

샘플 페이지는 `npm run demo`를 실행한 뒤 [http://127.0.0.1:8080/](http://127.0.0.1:8080/)에서 확인하세요.

## 게임패드 조작

| 모드 | 입력 | 동작 |
| --- | --- | --- |
| 평상시 | 십자키 | 페이지에 화살표 키 입력. 페이지가 입력을 막지 않으면 페이지 스크롤과 기본 폼 조작을 보조합니다. |
| 평상시 | R스틱 | 화면 안의 가상 커서를 이동합니다. |
| 평상시 | R3 / R1 / R2 | 커서 위치에서 가운데 / 오른쪽 / 왼쪽 클릭 |
| 평상시 | A / B | Enter / Escape |
| 평상시 | X | 스페이스 바 입력 |
| 평상시 | L1 / L2 | 브라우저 뒤로 / 앞으로 |
| spotlight 표시 중 | A / B | 현재 선택 요소에 Enter / 오버레이 취소 |
| iframe 내부 | Y / spotlight가 꺼진 상태의 B·Escape | 바로 위 부모 프레임으로 복귀 |
| spotlight 표시 중 | L1 / L2 / X | 후보 역순 / 정순 / 정순 순회 |
| spotlight 표시 중 | R스틱 회전 | 설정한 회전량마다 후보를 한 칸씩 순환. 시계 방향은 정순, 반시계 방향은 역순 |
| Y를 누르는 동안 | 십자키 | 커서 위치에서 위·아래·좌·우 휠 조작 |
| Y를 누르는 동안 | L스틱 회전 | 시계 방향은 커서 위치에서 아래로, 반시계 방향은 위로 스크롤 |
| Y를 누르는 동안 | L1 / L2 | 이전 / 다음 탭 |

가상 커서는 평상시 R스틱으로 움직이거나 커서 위치에서 클릭·휠 조작을 할 때 표시됩니다. 마지막 조작 후 약 1초 뒤 숨고, 위치는 기억합니다.

spotlight 표시 중 X와 L2는 탐색 후보를 거리순 정방향으로, L1은 역방향으로 순회하고 현재 선택 요소에 포커스를 옮깁니다. 선택할 때 가상 커서 위치도 해당 요소로 옮기지만, 커서는 표시하지 않습니다. A는 현재 선택 요소를 실행하고, B는 오버레이를 취소합니다. L3는 오버레이를 고정·해제하고 R1/R2/R3는 가상 커서 위치에서 클릭합니다. L스틱이 중립으로 돌아오면 고정되지 않은 오버레이를 숨깁니다. L3로 고정하면 중립에서도 유지되고, 현재 선택 요소를 실행하거나 L3를 다시 누르면 고정이 풀립니다. B 취소 후에는 L스틱을 중립에 놓았다가 다시 기울여 탐색을 시작합니다.

spotlight 탐색 중이거나 Y를 누르고 있는 동안에는 Xbox 컨트롤러 아이콘과 간단한 동작 설명을 화면 하단에 가로로 표시합니다. 설정의 `하단 조작 가이드`에서 끌 수 있으며 기본값은 표시입니다.

spotlight는 화면 중앙의 원형 캡에서 L스틱 방향으로 뻗습니다. 설정한 시작 크기와 도착 크기 사이에서 폭이 선형으로 변합니다. 시작 크기가 0이면 현재 원뿔 모양이고, 시작 크기와 도착 크기가 같으면 폭이 일정한 원통 모양입니다.

### iframe 탐색

화면에 보이는 iframe도 탐색 후보에 포함됩니다. 현재 선택된 iframe은 일반 선택 요소의 라임색 외곽선과 구분되는 하늘색 외곽선으로 표시합니다. iframe을 선택한 뒤 L스틱을 중립으로 놓거나 B로 spotlight를 해제하면 해당 프레임으로 탐색 대상을 옮깁니다. 다음 L스틱 입력은 iframe 내부에서 시작하며, 중첩 iframe에서는 한 단계씩 이동합니다. iframe 안에서 Y를 누르거나 spotlight가 꺼진 상태에서 B 또는 Escape를 누르면 바로 위 부모 프레임으로 돌아갑니다. spotlight가 표시 중일 때 B는 기존처럼 오버레이를 해제합니다.

게임패드 상태는 최상위 프레임에서 한 번 읽고 현재 탐색 프레임에 전달하므로 프레임 수만큼 입력이 중복 실행되지 않습니다.

Y를 누르면 표시 중인 spotlight와 고정을 취소합니다. Y 모드에서 십자키는 휠 조작, L스틱 회전은 세로 스크롤, L1/L2는 이전/다음 탭, A/B는 Enter/Escape로 동작합니다. 십자키는 표준 버튼 12–15, R스틱은 축 2·3, A/B/X/Y는 버튼 0–3, L1/R1/L2/R2는 버튼 4–7, L3/R3는 버튼 10·11을 사용합니다. 트리거 입력 임계값 기본값은 0.5입니다.

Y를 누른 채 L스틱을 돌릴 때의 스크롤과 평상시 R스틱 가상 커서 이동에는 서로 다른 속도 곡선을 적용합니다. 설정에서 각 입력의 최대 속도를 픽셀/초 단위로 정하고, 그래프 점을 직접 끌어 25%, 50%, 75% 입력 지점의 속도 비율을 조절할 수 있습니다. 세 점은 매끄러운 베지어 곡선으로 연결됩니다. 양 끝점은 고정되고 속도는 입력이 커질수록 낮아지지 않습니다. 기본 곡선은 선형 기준선 아래에서 휘어 큰 입력에서 빠르게 가속합니다. Y+L스틱 스크롤은 초당 1회전일 때 설정된 최대 속도에 도달하며, 십자키 스크롤도 같은 최대 속도를 사용합니다.

| 탐색 설정 | 기본값 | 동작 |
| --- | --- | --- |
| L스틱 데드존 | 0.2 | 이 값보다 큰 입력으로 방향 오버레이를 표시합니다. |
| 도착 크기 | 30% | 화면 짧은 변을 기준으로 spotlight 끝의 폭을 정합니다. |
| 시작 크기 | 0% | 화면 짧은 변을 기준으로 중앙 원형 캡의 지름을 정합니다. 0%면 캡이 없고, 도착 크기와 같으면 폭이 일정합니다. |
| 후보 전환에 필요한 R스틱 회전량 | 70°/후보 | 최대 기울기에서 설정 각도만큼 돌릴 때 spotlight 후보를 한 칸 이동합니다. |
| 최대 스크롤 속도 | 2200픽셀/초 | Y+L스틱은 초당 1회전에서 이 속도에 도달하며, 십자키 대각선 입력을 포함한 최대 속도입니다. |
| Y + L스틱 스크롤 속도 곡선 | 25% 입력 → 10%, 50% → 30%, 75% → 62% | Y 유지 중 L스틱 회전으로 스크롤할 때 적용합니다. |
| 최대 가상 커서 속도 | 1800픽셀/초 | 속도 곡선이 최대값에 도달했을 때의 R스틱 커서 이동 속도입니다. |
| R스틱 가상 커서 속도 곡선 | 25% 입력 → 8%, 50% → 28%, 75% → 62% | 평상시 R스틱으로 가상 커서를 이동할 때 적용합니다. |
| L3 | 버튼 10 | 방향 오버레이를 고정하거나 고정을 풉니다. |
| X | 버튼 2 | 평상시에는 스페이스 바를 입력하고, spotlight 중에는 거리순 탐색 후보를 순회해 현재 선택 요소에 웹 문서 포커스를 옮깁니다. |
| 탐색 후보 목록 변경 시 | 첫 탐색 후보 | 설정에 따라 이전 현재 선택 요소를 유지할 수 있습니다. |
| 순번 표시 | 표시 | 비표시로 바꾸면 후보 번호와 배지가 숨겨집니다. 표시할 때 글씨는 10px이며, 현재 선택 후보 외의 번호에는 어두운 배지를 붙입니다. |
| 하단 조작 가이드 | 표시 | spotlight 탐색 또는 Y 유지 중 Xbox 버튼 아이콘과 간단한 설명을 화면 아래쪽에 표시합니다. |
| spotlight 포함 판정 / 거리 | 요소 중심점 / 중심점 거리 | 탐색 후보와 순서를 정합니다. |

데드존 범위는 0.05–0.6, 도착 크기와 시작 크기는 화면 짧은 변의 0–100%, 트리거 임계값은 0.1–1입니다. 설정은 저장되어 재시작 후에도 유지됩니다.

## 입력 범위와 제한

-   **실제 운영체제 포인터 이동:** 일반 Chrome 확장 API로는 제공할 수 없습니다. R스틱은 페이지 위에 별도로 그리는 가상 커서를 움직입니다. 일반 포인터와 브라우저 UI는 이동하지 않습니다. 페이지에는 합성 포인터 이동 이벤트를 보내지만 CSS `:hover` 표시는 바뀌지 않을 수 있습니다.
    
-   **키보드·마우스 이벤트:** 페이지 DOM에 합성 이벤트를 전달합니다. MDN에 따르면 `dispatchEvent()`와 `HTMLElement.click()` 이벤트의 `isTrusted`는 `false`입니다. 웹 페이지의 키·마우스 처리기와 일반 링크·버튼은 동작할 수 있지만, 신뢰 입력을 요구하는 사이트의 인증·보안 입력에는 동등하지 않습니다.
    
-   **R1 오른쪽 클릭:** 페이지에 `contextmenu` 이벤트를 보내지만 Chrome 네이티브 우클릭 메뉴를 띄우지는 못합니다.
    
-   **R3 가운데 클릭:** 페이지에 `auxclick`을 보내고, 취소되지 않은 링크는 비활성 새 탭으로 엽니다.
    
-   **Y+휠 조작:** 십자키와 L스틱 회전이 가상 커서 위치의 페이지에 `wheel` 이벤트를 보냅니다. 기본 동작이 취소되지 않으면 해당 스크롤 영역을 직접 움직입니다.
    
-   `chrome.debugger`와 Chrome DevTools Protocol은 탭 안으로 입력
