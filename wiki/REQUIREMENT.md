# 요구사항 요약

## 제품 목표

- 표준 게임패드로 브라우저를 탐색한다. 초기 제공물은 Chrome Manifest V3 확장이다.
- 게임패드 입력은 현재 포커스된 탭에서만 처리하고, 탭 이동 시 입력 소유권도 옮긴다.

## 조작

### 평상시

| 입력 | 동작 |
| --- | --- |
| 십자키 | 웹 페이지에 키보드 화살표 입력 |
| R스틱 | 페이지 위 가상 마우스 커서 이동. 이동 중 잠시 표시 |
| R3 / R1 / R2 | 가상 커서 위치에서 가운데 / 오른쪽 / 왼쪽 클릭 |
| A / B | Enter / Escape 입력 |
| X | 스페이스 바 입력 |
| L1 / L2 | 브라우저 뒤로 / 앞으로 |

가상 커서는 R스틱 이동이나 커서 위치의 클릭·휠 조작 때 표시하고, 입력 후 약 1초가 지나면 숨긴다. 숨겨져도 위치는 기억한다.

### 탐색 spotlight 표시 중

- A는 현재 선택 요소에 Enter를 수행하고 B는 오버레이를 취소한다.
- X는 탐색 후보를 거리순으로 순회하고 현재 선택 요소에 웹 문서 포커스를 옮긴다. 가상 커서 위치도 선택 요소로 이동시키되, 이때 커서를 표시하지 않는다.
- L1은 후보를 역순으로 순회한다. L2는 X와 같은 정순 탐색 키다.
- R스틱을 시계 방향으로 돌리면 선택 후보를 정순 순환하고, 반시계 방향으로 돌리면 역순 순환한다. 설정에서 후보 하나 전환에 필요한 회전량을 조절한다.
- L3는 spotlight 고정·해제 토글이다. 고정 중 중립으로 돌아와도 요소 실행 전까지 오버레이를 유지한다.
- B로 취소한 오버레이는 L스틱이 중립을 거친 뒤 다시 표시할 수 있다.

### Y를 누르는 동안

- Y를 누르면 spotlight를 취소하고 고정을 해제한다.
- L1/L2는 이전/다음 탭으로 이동한다.
- 십자키는 가상 커서 위치에서 위·아래·좌·우 휠 조작을 한다.
- L스틱을 시계 방향으로 돌리면 가상 커서 위치의 스크롤 영역을 아래로, 반시계 방향으로 돌리면 위로 스크롤한다.
- A/B는 기본 Enter/Escape 동작을 한다.

## 조작 가이드

- spotlight 표시 중 또는 Y를 누르는 동안 화면 하단에 Xbox 표준 버튼 아이콘과 간단한 동작 설명을 가로로 표시한다.
- 가이드는 하단에서 부드럽게 올라오고, 어두운 검은색 그라데이션 배경은 위쪽으로 흐려진다.
- 설정의 `하단 조작 가이드`에서 표시/비표시를 선택한다. 기본값은 표시다.

## 오버레이와 탐색 후보

- L스틱 방향에 맞춰 화면 중앙에서 가장자리까지 spotlight 영역을 정한다. 방향 입력을 부드럽게 보정해 잔떨림을 줄인다.
- `도착 크기`와 `시작 크기`는 화면 짧은 변 대비 비율로 설정한다. 도착 크기는 spotlight 끝의 폭, 시작 크기는 화면 중앙 원형 캡의 지름이다. 시작 크기가 0이면 원뿔형이고, 두 크기가 같으면 폭이 일정한 원통형이다. 두 크기 사이의 폭은 길이에 따라 선형으로 변한다.
- spotlight 안쪽은 밝게 두고 바깥을 어둡게 처리한다. 영역 경계와 방향 축은 표시하지 않는다.
- spotlight 포함 판정에 맞는 클릭 가능한 가시 요소와 iframe 요소를 거리순 탐색 후보로 삼는다. 일반 후보에는 외곽선을 표시하지 않는다.
- X로 순회해 현재 선택 요소를 정한다. 일반 선택 요소는 얇은 라임색(primary) 외곽선으로 표시하고, 선택된 iframe은 primary와 다른 하늘색 외곽선으로 구분한다. A로 현재 선택 요소를 실행한다.
- 페이지 오버레이의 상단 텍스트와 상태 배지는 표시하지 않는다. 후보 순번은 기본적으로 표시하고, 설정의 `순번 표시`에서 표시/비표시를 선택한다. 표시할 때는 10px 글씨를 사용하며, 현재 선택 요소는 배경 없이 선택 색상 글자로, 다른 후보는 배경 배지와 함께 표시한다. 번호 위치와 무관하게 기본 spotlight 포함 판정은 요소 중심점 기준이다.
- 고정되지 않은 오버레이는 L스틱이 중립으로 돌아오면 숨긴다.

## iframe 탐색

- iframe을 선택한 상태에서 L스틱 중립 또는 B로 spotlight를 해제하면 선택한 iframe을 기억한다. 다시 spotlight를 시작하면 해당 iframe 내부에서 탐색한다.
- iframe 내부에서 Y를 누르면 iframe 포커스를 해제하고 부모로 복귀한다.
- spotlight 오버라이드가 없는 상태에서는 ESC 또는 B로도 부모로 복귀한다. spotlight 표시 중 B는 오버레이 해제로 처리한다.
- 중첩 iframe에서는 바로 위 부모 프레임으로 한 단계 복귀한다.
- 최상위 프레임만 게임패드를 읽고 현재 탐색 프레임에 입력 상태를 전달해 중복 처리를 막는다.

## 설정과 기술 범위

- 데드존, spotlight 시작·도착 크기, 트리거 임계값, 후보 포함·정렬·유지 기준, 두 입력의 최대 속도와 속도 곡선을 설정하고 저장한다.
- Y+L스틱 스크롤과 R스틱 가상 커서 이동은 각각 별도 입력-속도 곡선을 사용한다. 기본 곡선은 기존 선형 반응보다 초·중반 입력에 더 빠르게 반응한다.
- 설정 그래프에서 두 곡선의 25%, 50%, 75% 입력 지점을 직접 편집하고 미리보기를 확인한다. 점은 매끄러운 베지어 곡선으로 연결한다. 시작점과 끝점은 고정하며, 속도는 입력이 커질수록 낮아지지 않는다.
- 최대 가상 커서 속도는 픽셀/초로 설정한다. 기본값은 1800픽셀/초다. 최대 스크롤 속도 기본값은 2200픽셀/초이며, Y+L스틱은 초당 1회전에서 이를 상한으로 삼고 십자키 대각선 입력을 포함한 스크롤 속도도 같은 상한을 사용한다.
- spotlight 중 R스틱 후보 순환은 후보 전환에 필요한 회전량을 도/후보 단위로 설정한다. 기본값은 70°다.
- 브라우저 콘텐츠 입력은 합성 DOM 이벤트로 제공한다. 일반 Chrome 확장은 운영체제 마우스 포인터를 이동하지 않으며 신뢰 입력 전용 사이트·네이티브 컨텍스트 메뉴 동작에는 제한이 있다.
- Gamepad API, 입력 해석, spotlight 판정·후보 정렬을 브라우저 연동 코드와 분리한다.
