# 용어

## 게임패드 입력

- **표준 매핑**: 브라우저 Gamepad API의 일반적인 Xbox 버튼 번호 배열.
- **십자키**: 표준 버튼 12–15. 평상시에는 화살표 키, Y를 누르면 휠 조작을 한다.
- **가상 커서**: 평상시 R스틱으로 움직이는 페이지 내부 표시. 탐색 spotlight 중 R스틱 회전은 후보를 순환한다. spotlight에서 요소를 선택하면 커서 위치를 해당 요소로 옮기되 표시하지 않는다. R스틱 이동이나 커서 위치의 클릭·휠 조작 때 나타나며 약 1초 뒤 숨겨져도 위치를 기억한다. 운영체제 마우스 포인터는 움직이지 않는다.
- **속도 곡선**: 데드존 이후 스틱 입력 크기를 설정된 최대 속도의 비율로 바꾸는 설정. 그래프에서 입력 25%, 50%, 75% 지점을 직접 끌어 편집하고 매끄러운 베지어 곡선으로 연결한다. 시작·끝점은 고정한다.
- **후보 전환 회전량**: spotlight 중 R스틱을 돌려 후보 하나를 이동하는 데 필요한 회전 각도. 설정값이 클수록 더 크게 돌려야 한다.
- **R3**: 오른쪽 스틱 클릭. 가상 커서 위치에서 가운데 클릭을 수행한다.
- **R1**: 오른쪽 범퍼. 가상 커서 위치에서 오른쪽 클릭 이벤트를 보낸다.
- **R2**: 오른쪽 트리거. 가상 커서 위치에서 왼쪽 클릭을 수행한다.
- **X**: 버튼 2. 평상시에는 스페이스 바 키 입력, spotlight 중에는 탐색 후보 정순 순회에 사용한다.
- **L1**: 왼쪽 범퍼. spotlight 중 후보 역순 순회, 그 외 평상시 브라우저 뒤로 또는 Y 유지 중 이전 탭으로 이동한다.
- **L2**: 왼쪽 트리거. spotlight 중 X와 같은 정순 후보 순회, 그 외 평상시 브라우저 앞으로 또는 Y 유지 중 다음 탭으로 이동한다.
- **Y 모드**: Y를 누르면 spotlight를 취소하고 고정을 해제한 뒤, 십자키와 L스틱 회전을 휠 조작으로 바꾸는 입력 모드. L1/L2는 이전/다음 탭으로, A/B는 Enter/Escape로 동작한다.
- **조작 가이드**: spotlight 또는 Y 유지 중 화면 하단에 표시하는 Xbox 컨트롤러 입력 아이콘과 짧은 동작 설명. `하단 조작 가이드` 설정 기본값은 `표시`다.

## 탐색

- **spotlight**: 특정 영역을 밝게 드러내고 주변을 어둡게 하는 시각 효과.
- **탐색 spotlight**: L스틱 방향을 따라 화면 중앙에서 가장자리까지 드러내는 탐색 영역. 시작 크기와 도착 크기에 따라 폭이 변한다.
- **도착 크기**: 화면 짧은 변 대비 비율로 설정하는 spotlight 끝의 폭.
- **시작 크기**: 화면 짧은 변 대비 비율로 설정하는 화면 중앙 원형 캡의 지름. 도착 크기와 같으면 spotlight 폭이 일정하다.
- **spotlight 오버레이**: spotlight 효과를 화면 위에 표시하는 레이어.
- **탐색 후보**: spotlight 포함 판정에 따라 후보 목록에 들어가고 X/L2로 정순, L1으로 역순 순회하는 클릭 가능한 요소. 일반 후보 외곽선은 표시하지 않는다.
- **현재 선택 요소**: X로 순회해 현재 선택한 탐색 후보. 얇은 라임색 외곽선으로 표시하고, A로 실행한다.
- **후보 순번**: 거리순 후보 목록에서의 1부터 시작하는 위치 번호. `순번 표시` 설정이 `표시`일 때 요소 왼쪽 위에 10px 글씨로 나타난다. 기본값은 `표시`이며, 현재 선택 요소는 배경 없이 라임색 글자로 표시한다.
- **순번 배지**: 현재 선택 요소를 제외한 탐색 후보 순번 뒤에 표시하는 작은 어두운 배경 컨테이너. 외곽선은 표시하지 않는다.
- **탐색 포커스**: X 순회로 현재 선택 요소에 옮겨진 웹 문서의 실제 포커스.
- **iframe**: 웹 문서를 내부에 표시하는 하위 프레임. 탐색 후보로 선택하면 spotlight를 해제한 뒤 그 내부에서 탐색을 다시 시작한다. Y 또는 spotlight가 꺼진 상태의 B·Escape는 바로 위 부모 프레임으로 돌아간다.
- **iframe 탐색 후보**: 화면에 보이는 `iframe` 요소. 현재 선택 시 일반 후보의 라임색 대신 하늘색 외곽선을 표시한다.
- **고정**: L3로 오버레이를 유지하는 상태. 현재 선택 요소를 실행하면 해제한다.
- **트리거 임계값**: L2/R2의 정규화 입력값을 누름으로 판정하는 기준.

## GUI 표시명

- 상태: `탐색 대기 중`, `가상 커서`, `스크롤 모드`, `탐색 중`, `고정`.
- 설정: `스틱 데드존`, `도착 크기`, `시작 크기`, `트리거 입력 임계값`, `탐색 후보 목록 변경 시`, `순번 표시`, `하단 조작 가이드`, `spotlight 포함 판정`, `거리 계산`, `거리가 같을 때`, `후보 전환에 필요한 R스틱 회전량`, `최대 스크롤 속도`, `최대 가상 커서 속도`, `Y + L스틱 스크롤 속도`, `R스틱 가상 커서 속도` 곡선.
- 클릭 동작은 페이지 이벤트를 합성한다. R1은 브라우저 네이티브 컨텍스트 메뉴와 같지 않을 수 있다.
